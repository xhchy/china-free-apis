## 为什么要做这个

找免费 API 时，搜到的十有八九是：

- 要注册账号、绑定手机、甚至实名认证
- 号称免费，实际限制到没法用
- 三年前的项目，接口早挂了
- 一堆广告和 SEO 垃圾站

这里只收录**真正免注册、无需实名、直接 GET 调用**的国内公益接口，并且提供脚本**自动探活**——
清单里的链接挂了，你一眼就能看到。

## 快速开始

```bash
# 无需安装任何依赖（Python 3.8+ 标准库）
python check.py              # 检查所有接口是否存活
python check.py --json       # JSON 输出，方便接 CI
python check.py --timeout 5  # 自定义超时
```

单个接口直接调用：

```bash
curl "https://api.aa1.cn/doc/iphq.html"      # 看文档
curl "https://api.qqsuu.cn"                   # 大米API 首页
```

## 收录标准

✅ 只收：
- 无需注册或只需免费注册
- **不要身份证 / 信用卡 / 实名认证**
- 有明确文档
- 个人开发者能正常用

❌ 不收：
- 要实名的国内官方 API（智谱/Kimi/百炼/火山方舟等）
- 要信用卡的海外服务
- 已经停运的（如 tenapi.cn，2024-11-27 已停）
- 纯 SEO 垃圾站

## 自动探活

`check.py` 会遍历 `apis.json` 里所有接口，发一个最小 GET 请求，记录：

- HTTP 状态码
- 响应时间
- 是否返回预期内容类型

```bash
$ python check.py

正在检查 12 个接口...
✅ 免费API (aa1.cn)              200   312ms
✅ 大米API                       200   189ms
❌ TenAPI                       DEAD  (已停运 2024-11-27)
...
存活 11/12  |  平均响应 286ms
```

配合 GitHub Actions 可以每天自动跑一次，结果写进 `STATUS.md`。

## 贡献

发现新的免费 API？欢迎提 PR，按这个格式加到 `apis.json`：

```json
{
  "name": "接口名称",
  "url": "https://...",
  "category": "天气/IP/热搜/...",
  "auth": "none",
  "note": "免费额度说明"
}
```

**请不要提交**：需要实名的、需要信用卡的、已经停运的、带营销软文的。
